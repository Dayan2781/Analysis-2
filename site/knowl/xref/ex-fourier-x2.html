Жишээ 11.7 \(f(x) = x^2\text{,}\) \(-\pi\le x\le\pi\).

Тэгш тул \(b_n = 0\text{,}\) \(a_0 = \frac2\pi\int_0^\pi x^2dx = \frac{2\pi^2}{3}\text{;}\) хоёр удаа хэсэгчлэн интегралчилбал \(a_n = \frac{4(-1)^n}{n^2}\text{:}\)
\begin{equation*} x^2 = \frac{\pi^2}{3} + 4\sum_{n=1}^\infty\frac{(-1)^n\cos nx}{n^2} \qquad (|x|\le\pi). \end{equation*}
\(x^2\)-ийн \(2\pi\) үетэй үргэлжлэл тасралтгүй тул тэнцэтгэл бүх цэгт биелнэ (доорх Теорем 11.4). \(x = \pi\text{:}\) \(\pi^2 = \frac{\pi^2}{3} + 4\sum\frac{1}{n^2}\text{,}\) иймд
\begin{equation*} \boxed{\ \sum_{n=1}^\infty\frac{1}{n^2} = \frac{\pi^2}{6}\ } \qquad\text{ба}\quad x = 0: \ \sum_{n=1}^\infty\frac{(-1)^{n+1}}{n^2} = \frac{\pi^2}{12}. \end{equation*}
