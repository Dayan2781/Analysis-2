Өгүүлбэр 11.28.

\(f, g\) нь \(\R\) дээр абсолют интегралчлагдах, \(a\in\R\text{,}\) \(\lambda\ne0\) бол
  1. \(\widehat{\alpha f + \beta g} = \alpha\hat f + \beta\hat g\text{;}\)
    🔗
  2. (шилжилт) \(\widehat{f(x - a)}(\xi) = e^{-ia\xi}\hat f(\xi)\text{,}\) (модуляц) \(\widehat{e^{iax}f(x)}(\xi) = \hat f(\xi - a)\text{;}\)
    🔗
  3. (масштаб) \(\widehat{f(\lambda x)}(\xi) = \frac{1}{|\lambda|}\hat f\bigl(\frac{\xi}{\lambda}\bigr)\text{;}\)
    🔗
  4. (уламжлал) \(f\) нь тасралтгүй дифференциалчлагдах, \(f'\) мөн абсолют интегралчлагдах бол \(\widehat{f'}(\xi) = i\xi\hat f(\xi)\text{;}\)
    🔗
  5. (хувиргалтын уламжлал) \(xf(x)\) абсолют интегралчлагдах бол \(\hat f\) дифференциалчлагдах ба \((\hat f)'(\xi) = \widehat{(-ixf)}(\xi)\text{.}\)
    🔗
🔗
🔗

Баталгаа.
1–3 нь өргөтгөсөн интегралд хувьсагч солихоос шууд гарна. 4: \(f(x) = f(0) + \int_0^xf'\) ба \(f'\) абсолют интегралчлагдах тул \(\lim_{x\to\pm\infty}f(x)\) оршино; \(f\) абсолют интегралчлагдах тул уг хязгаарууд \(0\text{.}\) Хэсэгчлэн интегралчилбал
\begin{equation*} \int_{-A}^{A}f'(x)e^{-i\xi x}dx = \Bigl[f(x)e^{-i\xi x}\Bigr]_{-A}^{A} + i\xi\int_{-A}^{A}f(x)e^{-i\xi x}dx \xrightarrow[A\to\infty]{} i\xi\hat f(\xi). \end{equation*}
5: \(\frac{\partial}{\partial\xi}\bigl(f(x)e^{-i\xi x}\bigr) = -ixf(x)e^{-i\xi x}\) ба \(|{-ixf(x)e^{-i\xi x}}| = |xf(x)|\) нь \(\xi\)-ээс хамааралгүй интегралчлагдах мажорант тул параметрээр дифференциалчлах теорем (12-р хичээл) хэрэглэгдэнэ.
