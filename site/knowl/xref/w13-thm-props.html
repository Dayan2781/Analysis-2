Теорем 13.21.

\(E, E_1, E_2\) нь Жорданы утгаар хэмжигдэх олонлогууд, \(f, g\) тэдгээр дээр интегралчлагдах байг.
  1. Шугаман чанар. \(\int_E(\alpha f + \beta g) = \alpha\int_E f + \beta\int_E g\text{.}\)
    🔗
  2. Монотон чанар. \(f\le g\) бол \(\int_E f\le\int_E g\text{;}\) ялангуяа \(\bigl|\int_E f\bigr|\le\int_E|f|\text{.}\)
    🔗
  3. Нэмэх чанар. \(E_1\cup E_2\text{,}\) \(E_1\cap E_2\) хэмжигдэх олонлогууд бөгөөд \(|E_1\cap E_2| = 0\) бол \(\int_{E_1\cup E_2} f = \int_{E_1}f + \int_{E_2} f\text{.}\)
    🔗
  4. Дундаж утгын теорем. \(m\le f\le M\) бол \(m|E|\le\int_E f\le M|E|\text{.}\) Хэрэв \(E\) компакт, холбоост (дурын хоёр цэгийг \(E\) дотор тасралтгүй муруйгаар холбож болох), \(f\) тасралтгүй бол \(\int_E f = f(\xi)|E|\) байх \(\xi\in E\) олдоно.
    🔗
🔗
🔗

Баталгаа.
1, 2 нь Риманы нийлбэрийн харгалзах чанар ба хязгаарт шилжихээс гарна (\(|f|\) интегралчлагдах нь Мөрдөлгөө 13.4).
🔗
3. \(\partial(E_1\cup E_2)\text{,}\) \(\partial(E_1\cap E_2)\subset\partial E_1\cup\partial E_2\) тул эдгээр нь хэмжигдэх олонлог. \(f_{E_1\cup E_2} + f_{E_1\cap E_2} = f_{E_1} + f_{E_2}\) ба \(|f_{E_1\cap E_2}|\le\sup|f|\cdot\chi_{E_1\cap E_2}\) тул \(\bigl|\int f_{E_1\cap E_2}\bigr|\le\sup|f|\cdot|E_1\cap E_2| = 0\text{.}\)
🔗
4. Эхний хэсэг нь 2-оос (\(\int_E c = c|E|\)). \(|E| = 0\) бол илэрхий. Үгүй бол \(m = \min_E f\text{,}\) \(M = \max_E f\) гэж аваад \(\mu = \frac{1}{|E|}\int_E f\in[m,M]\text{.}\) \(f(p) = m\text{,}\) \(f(q) = M\) цэгүүдийг холбосон тасралтгүй \(\gamma: [0,1]\to E\) муруй дээр \(f\circ\gamma\) тасралтгүй тул завсрын утгын теоремоор \(f(\gamma(t)) = \mu\) байх \(t\) олдоно.
