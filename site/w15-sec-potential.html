    Хэсэг 15.6 Интеграл замаас хамаарахгүй байх нөхцөл

    Энэ хэсэгт \(G\subset\R^n\) нь муж (задгай, холбоост олонлог), \(F = (F_1,\dots,F_n)\) нь \(G\) дээр тасралтгүй, \(\omega = \sum F_k\,dx_k\) гэж үзнэ. Задгай холбоост олонлогийн дурын хоёр цэгийг \(G\)-д агуулагдах хугархай шугамаар (координатын тэнхлэгтэй параллель хэрчмүүдээр ч) холбож болдгийг ашиглана.

    Тодорхойлолт 15.9.

    \(\nabla U = F\text{,}\) өөрөөр хэлбэл \(\frac{\partial U}{\partial x_k} = F_k\) (\(k = 1,\dots,n\)) байх \(U\in C^1(G)\) функцийг \(F\)-ийн потенциал гэнэ. Ийм \(U\) олдвол \(F\)-ийг потенциалт талбар, \(\omega\)-г бүтэн дифференциал гэнэ: \(\omega = dU\text{.}\)
    🔗
    🔗

    Теорем 15.6.

    \(G\) муж дээр тасралтгүй \(F\)-ийн хувьд дараах нөхцлүүд эн чацуу:
    1. \(G\)-д агуулагдах дурын хэсэгчлэн гөлгөр \(\gamma\)-ийн хувьд \(\int_\gamma F\cdot dr\) нь зөвхөн \(\gamma\)-ийн эхлэл ба төгсгөлөөс хамаарна;
      🔗
    2. \(G\)-д агуулагдах дурын хэсэгчлэн гөлгөр битүү \(\gamma\)-ийн хувьд \(\oint_\gamma F\cdot dr = 0\text{;}\)
      🔗
    3. \(F\) нь \(G\) дээр потенциалтай.
      🔗
    Энэ үед \(A\)-аас \(B\) хүртэлх дурын замын хувьд \(\int_\gamma F\cdot dr = U(B) - U(A)\text{.}\)
    🔗
    🔗

    Баталгаа.
    (3)\(\Rightarrow\)(1). \(\gamma\) гөлгөр, \(r:[a,b]\to G\) бол гинжин дүрмээр \(\frac{d}{dt}U(r(t)) = \nabla U(r(t))\cdot r'(t) = F(r(t))\cdot r'(t)\) — тасралтгүй функц. Ньютон–Лейбницээр (Теорем 4.2) \(\int_\gamma F\cdot dr = U(r(b)) - U(r(a))\text{.}\) Хэсэгчлэн гөлгөр бол хэсгүүдийн нийлбэр телескоп болж мөн \(U(B) - U(A)\) гарна.
    🔗
    (1)\(\Rightarrow\)(2). Битүү \(\gamma\)-ийн дурын \(A\ne B\) хоёр цэгээр түүнийг \(\gamma = \gamma_1 + \gamma_2\) (\(\gamma_1\text{:}\) \(A\to B\text{,}\) \(\gamma_2\text{:}\) \(B\to A\)) гэж хуваавал \(\gamma_1\) ба \(\gamma_2^-\) нь \(A\)-аас \(B\) хүртэлх замууд тул \(\oint_\gamma = \int_{\gamma_1} - \int_{\gamma_2^-} = 0\text{.}\)
    🔗
    (2)\(\Rightarrow\)(1). \(\gamma_1\text{,}\) \(\gamma_2\) нь \(A\)-аас \(B\) хүртэлх замууд бол \(\gamma_1 + \gamma_2^-\) битүү тул \(\int_{\gamma_1} - \int_{\gamma_2} = 0\text{.}\)
    🔗
    (1)\(\Rightarrow\)(3). \(A\in G\)-г бэхэлж, \(U(x) = \int_A^xF\cdot dr\) (дурын замаар; (1)-ээр зөв тодорхойлогдсон) гэе. \(x\in G\text{,}\) \(B(x,\delta)\subset G\text{,}\) \(0<|h|<\delta\) бол \(A\)-аас \(x\) хүртэлх замыг \([x, x+he_k]\) хэрчмээр (\(r(s) = x + se_k\text{,}\) \(s\in[0,h]\)) үргэлжлүүлж болох тул
    \begin{equation*} \frac{U(x+he_k) - U(x)}{h} = \frac1h\int_0^hF_k(x+se_k)\,ds\ \longrightarrow\ F_k(x) \quad (h\to0) \end{equation*}
    (интеграл тооллын үндсэн теорем, Теорем 4.1). Иймд \(\partial_kU = F_k\) тасралтгүй, \(U\in C^1(G)\text{.}\)
    🔗
    🔗

    Теорем 15.7 Зайлшгүй нөхцөл.

    \(F\in C^1(G)\) потенциалтай бол
    \begin{equation*} \frac{\partial F_i}{\partial x_j} = \frac{\partial F_j}{\partial x_i} \qquad (i,j = 1,\dots,n). \end{equation*}
    Хавтгайд: \(\dfrac{\partial P}{\partial y} = \dfrac{\partial Q}{\partial x}\text{;}\) огторгуйд: \(R_y = Q_z\text{,}\) \(P_z = R_x\text{,}\) \(Q_x = P_y\text{.}\)
    🔗
    🔗

    Баталгаа.
    \(F = \nabla U\text{,}\) \(F\in C^1\) тул \(U\in C^2\) ба Шварцын теоремоор \(\partial_j\partial_iU = \partial_i\partial_jU\text{.}\)
    🔗
    🔗
    Энэ нөхцлийг хангах \(\omega\)-г битүү хэлбэр гэнэ. Бүтэн дифференциал бүр битүү. Эсрэгээр нь мужийн хэлбэрээс хамаарна.
    🔗

    Тодорхойлолт 15.10.

    \(G\subset\R^2\) мужид агуулагдах дурын Жорданы муруйн дотоод муж бүхэлдээ \(G\)-д агуулагддаг бол \(G\)-г нэг холбоост гэнэ ("нүхгүй" муж). Жишээ нь дугуй, тэгш өнцөгт, дурын гүдгэр муж нэг холбоост; цагираг, \(\R^2\setminus\{0\}\) нэг холбоост биш.
    🔗
    🔗

    Теорем 15.8.

    \(G\subset\R^2\) нэг холбоост муж, \(P,Q\in C^1(G)\) ба \(G\) дээр \(P_y = Q_x\) бол \(P\,dx + Q\,dy\) нь \(G\) дээр бүтэн дифференциал.
    🔗
    🔗

    Баталгаа.
    \(G\)-ийн төв (эсвэл дурын бэхэлсэн цэг) \((x_0,y_0)\) гэе. \((x,y)\in G\) бүрд \((x_0,y_0)\text{,}\) \((x,y)\) оройтой, тэнхлэгүүдтэй параллель талтай \(\Pi\) тэгш өнцөгт \(G\)-д агуулагдана (дугуйн хувьд \(\Pi\)-ийн цэг бүр төвөөсөө \((x,y)\)-ээс хол биш). Хоёр зам авъя:
    \begin{equation*} \gamma': (x_0,y_0)\to(x,y_0)\to(x,y), \qquad \gamma'': (x_0,y_0)\to(x_0,y)\to(x,y). \end{equation*}
    \(\gamma' - \gamma''\) нь \(\pm\partial\Pi\) тул Грийний томьёогоор \(\int_{\gamma'} - \int_{\gamma''} = \pm\iint_\Pi(Q_x - P_y) = 0\) (\(\Pi\) доройтсон бол шууд). Иймд
    \begin{equation*} U(x,y) := \int_{x_0}^xP(s,y_0)\,ds + \int_{y_0}^yQ(x,s)\,ds = \int_{y_0}^yQ(x_0,s)\,ds + \int_{x_0}^xP(s,y)\,ds. \end{equation*}
    Эхний илэрхийллээс Теорем 4.1-ээр \(U_y = Q(x,y)\text{,}\) хоёр дахиас \(U_x = P(x,y)\text{.}\) \(P\text{,}\) \(Q\) тасралтгүй тул \(U\in C^1\text{.}\)
    🔗
    🔗

    Тэмдэглэл .

    Ерөнхий нэг холбоост \(G\)-ийн хувьд: дурын хэсэгчлэн гөлгөр Жорданы муруй \(\gamma\subset G\)-ийн дотоод муж \(D\subset G\) тул (Жорданы теорем ба Грийний томьёоны ерөнхий хэлбэр) \(\oint_\gamma = \pm\iint_D(Q_x - P_y) = 0\text{;}\) өөрийгөө огтолдог битүү муруйг энгийн битүү муруйнуудад задалж, Теорем 15.6-ийг хэрэглэнэ. \(\R^3\)-д ч \(\operatorname{rot}F = 0\) нөхцөл нэг холбоост мужид потенциалын оршин байхыг баталгаажуулдаг (дараагийн хичээл).
    🔗
    🔗

    Жишээ 15.9 Нэг холбоост нөхцөл зайлшгүй.

    \(G = \R^2\setminus\{(0,0)\}\) дээр
    \begin{equation*} \omega = \frac{-y\,dx + x\,dy}{x^2+y^2}, \qquad P = \frac{-y}{x^2+y^2}, \quad Q = \frac{x}{x^2+y^2}. \end{equation*}
    Шууд бодоход
    \begin{equation*} \frac{\partial P}{\partial y} = \frac{-(x^2+y^2) + 2y^2}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2} = \frac{(x^2+y^2) - 2x^2}{(x^2+y^2)^2} = \frac{\partial Q}{\partial x}, \end{equation*}
    тэгэхээр \(\omega\) битүү. Гэтэл \(x = \cos t\text{,}\) \(y = \sin t\) нэгж тойрог дээр
    \begin{equation*} \oint_{x^2+y^2 = 1}\omega = \int_0^{2\pi}\bigl(\sin^2t + \cos^2t\bigr)\,dt = 2\pi\ne0, \end{equation*}
    тул Теорем 15.6-аар \(\omega\) нь \(G\) дээр бүтэн дифференциал биш. Шалтгаан нь \(G\) "нүхтэй": Грийний томьёог \((0,0)\) агуулсан дугуйд хэрэглэж болохгүй (\(P\text{,}\) \(Q\) тэнд тодорхойлогдоогүй). Харин нэг холбоост \(G_0 = \R^2\setminus\{(x,0): x\le0\}\) дээр \(\omega = d\theta\text{,}\) энд \(\theta\in(-\pi,\pi)\) нь туйлын өнцөг. Ийм учраас \(\omega\)-г өнцгийн хэлбэр гэдэг.
    🔗
    🔗

    Мөрдөлгөө 15.9.

    \(\gamma\) нь \((0,0)\)-ийг дотроо агуулах, эерэг чиглэлтэй хэсэгчлэн гөлгөр Жорданы муруй бол \(\oint_\gamma\omega = 2\pi\text{;}\) \((0,0)\)-ийг дотроо агуулахгүй бол \(0\text{.}\)
    🔗
    🔗

    Баталгаа.
    Агуулахгүй бол \(\gamma\)-ийн дотоод муж дээр Грийнийг хэрэглэнэ. Агуулж байвал хангалттай бага \(\varepsilon\)-д \(C_\varepsilon\text{:}\) \(x^2+y^2 = \varepsilon^2\) тойрог \(\gamma\)-ийн дотор оршино. \(\gamma\) ба \(C_\varepsilon\)-ийн хоорондох \(D_\varepsilon\) мужид Грийнийг хэрэглэвэл (\(\partial D_\varepsilon = \gamma + C_\varepsilon^-\)) \(\oint_\gamma\omega - \oint_{C_\varepsilon}\omega = \iint_{D_\varepsilon}0 = 0\text{.}\) Жишээ 15.9-ийн тооцоо ямар ч радиуст адил тул \(\oint_{C_\varepsilon}\omega = 2\pi\text{.}\)
    🔗
    🔗

    Жишээ 15.10 Потенциал олох.

    \(F = (yz,\ xz,\ xy + 2z)\) нь \(\R^3\) дээр \(R_y = x = Q_z\text{,}\) \(P_z = y = R_x\text{,}\) \(Q_x = z = P_y\) нөхцлийг хангана. \(U_x = yz\)-ээс \(U = xyz + c(y,z)\text{;}\) \(U_y = xz + c_y = xz\) тул \(c = c(z)\text{;}\) \(U_z = xy + c'(z) = xy + 2z\) тул \(c = z^2\text{.}\) Иймд \(U = xyz + z^2\) ба \((0,0,0)\)-ээс \((1,2,3)\) хүртэлх дурын замаар
    \begin{equation*} \int_\gamma yz\,dx + xz\,dy + (xy+2z)\,dz = U(1,2,3) - U(0,0,0) = 6 + 9 = 15. \end{equation*}
    🔗
    🔗

    Тэмдэглэл Физик утга.

    Потенциалт (консерватив) хүчний талбайд хийх ажил замаас хамаарахгүй, битүү замаар хийх ажил \(0\) — энэ нь энерги хадгалагдах хууль юм. Ньютоны таталцлын талбай \(F = -\frac{k\,r}{|r|^3}\) нь \(\R^3\setminus\{0\}\) дээр \(U = \frac{k}{|r|}\) потенциалтай.
