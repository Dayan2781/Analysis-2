    Хэсэг 10.5 Зэрэгт цувааны нийлбэр олох

    Үндсэн арга: цувааг мэдэгдэх цуваа (ихэвчлэн геометр цуваа) болтол гишүүнчлэн дифференциалчлах эсвэл интегралчлах, дараа нь эсрэг үйлдэл хийх.
    🔗

    Жишээ 10.21.

    \(S(x) = \displaystyle\sum_{n=1}^\infty n^2x^n\text{,}\) \(|x|<1\text{.}\) \(\sum x^n = \frac{x}{1-x}\)-ээс \(x\frac{d}{dx}\) үйлдлийг хоёр удаа:
    \begin{equation*} \sum nx^n = \frac{x}{(1-x)^2}, \qquad \sum n^2x^n = x\Bigl(\frac{x}{(1-x)^2}\Bigr)' = \frac{x(1+x)}{(1-x)^3}. \end{equation*}
    \(x = \frac12\text{:}\) \(\sum\frac{n^2}{2^n} = 6\text{.}\)
    🔗
    🔗

    Жишээ 10.22.

    \(S(x) = \displaystyle\sum_{n=1}^\infty\frac{x^n}{n(n+1)}\text{,}\) \(|x|\le1\text{.}\) \(\bigl(xS(x)\bigr)'' = \bigl(\sum\frac{x^{n+1}}{n(n+1)}\bigr)'' = \sum x^{n-1} = \frac{1}{1-x}\text{.}\) Хоёр удаа интегралчилбал (\(xS\) ба түүний уламжлал \(0\) дээр \(0\)):
    \begin{equation*} \bigl(xS\bigr)' = -\ln(1-x), \qquad xS(x) = (1-x)\ln(1-x) + x. \end{equation*}
    Иймд \(x\ne0\) үед \(S(x) = 1 + \frac{(1-x)\ln(1-x)}{x}\text{.}\) Абелийн теоремоор \(x\to1^-\text{:}\) \(S(1) = 1\) — телескоп нийлбэр \(\sum\frac{1}{n(n+1)} = 1\)-тэй таарна.
