Теорем 12.5 Интегралчлалын дарааллыг солих.

\(f\in C(\Pi)\) бол
\begin{equation*} \int_c^d dy\int_a^b f(x,y)\,dx = \int_a^b dx\int_c^d f(x,y)\,dy. \end{equation*}
🔗
🔗

Баталгаа.
\(t\in[c,d]\)-д \(\varphi(t) = \int_c^t\Bigl(\int_a^b f(x,y)\,dx\Bigr)dy\text{,}\) \(\psi(t) = \int_a^b g(x,t)\,dx\text{,}\) \(g(x,t) = \int_c^t f(x,y)\,dy\) гэе. Теорем 12.3 ба интегралын үндсэн теоремоор \(\varphi'(t) = \int_a^b f(x,t)\,dx\text{.}\) Нөгөө талаас \(g\) ба \(\frac{\partial g}{\partial t} = f(x,t)\) хоёулаа \(\Pi\) дээр тасралтгүй (\(g\)-ийн тасралтгүй чанар: \(|g(x,t) - g(x',t')|\le|t-t'|\max|f| + (d-c)\max_y|f(x,y) - f(x',y)|\)), тул Теорем 12.4-ээр \(\psi'(t) = \int_a^b f(x,t)\,dx\text{.}\) Иймд \(\varphi' = \psi'\text{,}\) \(\varphi(c) = \psi(c) = 0\text{,}\) эндээс \(\varphi(d) = \psi(d)\text{.}\)
