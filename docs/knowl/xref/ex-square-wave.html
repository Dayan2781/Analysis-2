Жишээ 11.8 Тэгш өнцөгт долгион.

\(f(x) = \operatorname{sign}x\) (\(-\pi<x<\pi\text{,}\) \(f(0) = 0\)). Сондгой, \(b_n = \frac2\pi\int_0^\pi\sin nx\,dx = \frac{2(1 - (-1)^n)}{\pi n}\text{:}\)
\begin{equation*} \operatorname{sign}x\sim\frac4\pi\Bigl(\sin x + \frac{\sin3x}{3} + \frac{\sin5x}{5} + \cdots\Bigr). \end{equation*}
