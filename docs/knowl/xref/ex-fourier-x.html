Жишээ 11.6 \(f(x) = x\text{,}\) \(-\pi<x<\pi\).

Сондгой тул \(a_n = 0\text{,}\)
\begin{equation*} b_n = \frac2\pi\int_0^\pi x\sin nx\,dx = \frac2\pi\Bigl[-\frac{x\cos nx}{n}\Bigr]_0^\pi + \frac{2}{\pi n}\int_0^\pi\cos nx\,dx = \frac{2(-1)^{n+1}}{n}. \end{equation*}
\begin{equation*} x\sim2\sum_{n=1}^\infty\frac{(-1)^{n+1}\sin nx}{n} = 2\Bigl(\sin x - \frac{\sin2x}{2} + \frac{\sin3x}{3} - \cdots\Bigr). \end{equation*}
Доорх нийлэлтийн теоремоор энэ нь \((-\pi,\pi)\) дээр \(x\)-тэй тэнцүү, \(x = \pm\pi\) дээр \(0 = \frac{\pi + (-\pi)}{2}\text{.}\) \(x = \frac\pi2\) үед Лейбницийн цуваа гарна: \(\frac\pi4 = 1 - \frac13 + \frac15 - \cdots\text{.}\)
