Лемм 11.11 Риман–Лебег.

\(g\) нь \([a,b]\) дээр интегралчлагдах бол
\begin{equation*} \lim_{\lambda\to\infty}\int_a^bg(t)\sin\lambda t\,dt = 0, \qquad \lim_{\lambda\to\infty}\int_a^bg(t)\cos\lambda t\,dt = 0. \end{equation*}
Ялангуяа Фурьегийн коэффициентууд \(a_n, b_n\to0\text{.}\)

🔗

Баталгаа.
\(\varepsilon>0\text{.}\) \(g\) интегралчлагдах тул \(U(P,g) - L(P,g)<\varepsilon\) байх \(P = \{t_0<\dots<t_m\}\) хуваалт олдоно. \(m_i = \inf_{[t_{i-1},t_i]}g\) ба \(h = m_i\) (\([t_{i-1},t_i)\) дээр) шаталсан функц гэвэл \(0\le g - h\) ба \(\int_a^b(g - h)\le U - L<\varepsilon\text{.}\) Иймд
\begin{equation*} \Bigl|\int_a^bg\sin\lambda t\Bigr| \le \int_a^b(g - h) + \Bigl|\sum_{i=1}^m m_i\int_{t_{i-1}}^{t_i}\sin\lambda t\,dt\Bigr| \le \varepsilon + \sum_{i=1}^m|m_i|\cdot\frac{2}{\lambda}. \end{equation*}
\(\lambda\) хангалттай их үед хоёр дахь гишүүн \(<\varepsilon\text{.}\) \(\cos\)-ийн хувьд адил.
