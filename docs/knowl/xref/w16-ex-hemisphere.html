Жишээ 16.14 Хагас бөмбөрцгийн хүндийн төв.

\(\Sigma\text{:}\) \(x^2+y^2+z^2 = R^2\text{,}\) \(z\ge0\text{,}\) \(\rho\equiv1\text{.}\) \(z = R\cos\theta\text{,}\) \(dS = R^2\sin\theta\,d\theta\,d\varphi\text{:}\)
\begin{equation*} \iint_\Sigma z\,dS = \int_0^{2\pi}\!\!\int_0^{\pi/2}R^3\cos\theta\sin\theta\,d\theta\,d\varphi = \pi R^3. \end{equation*}
\(m = 2\pi R^2\) тул \(z_c = \frac R2\text{,}\) тэгш хэмээр \(x_c = y_c = 0\text{.}\)
