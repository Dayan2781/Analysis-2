Теорем 7.6.

  1. \(\sum a_n\) абсолют нийлэх \(\iff\) \(\sum a_n^+\) ба \(\sum a_n^-\) хоёулаа нийлнэ. Энэ үед \(\sum a_n = \sum a_n^+ - \sum a_n^-\text{.}\)
    🔗
  2. \(\sum a_n\) нөхцөлт нийлбэл \(\sum a_n^+ = \sum a_n^- = +\infty\text{.}\)
    🔗
🔗
🔗

Баталгаа.
(a) \(0 \le a_n^\pm \le |a_n|\) ба \(|a_n| = a_n^+ + a_n^-\) тул жиших шинжүүр ба шугаман чанараас гарна.
🔗
(b) \(\sum a_n^+\) нийлдэг гэж үзье. Тэгвэл \(a_n^- = a_n^+ - a_n\) тул \(\sum a_n^-\) мөн нийлж, (a)-аар \(\sum |a_n|\) нийлнэ — зөрчил. \(\sum a_n^-\)-ийн хувьд адилхан.
