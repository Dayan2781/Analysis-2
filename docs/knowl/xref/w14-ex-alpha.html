Жишээ 14.23.

\(\displaystyle\iint_{0<x^2 + y^2\le1}\frac{dx\,dy}{(x^2 + y^2)^{\alpha/2}} = \lim_{\varepsilon\to0}2\pi\int_\varepsilon^1r^{1 - \alpha}dr\) нь \(\alpha<2\) үед нийлж \(\frac{2\pi}{2 - \alpha}\)-тэй тэнцүү, \(\alpha\ge2\) үед сарнина. \(\displaystyle\iint_{x^2 + y^2\ge1}\frac{dx\,dy}{(x^2 + y^2)^{\alpha/2}}\) нь \(\alpha>2\) үед л нийлнэ. \(\R^n\)-д харгалзах босго нь \(\alpha = n\) (Өгүүлбэр 14.26).
