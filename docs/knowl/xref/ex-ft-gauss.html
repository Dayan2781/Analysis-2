Жишээ 11.35 Гауссын функц.

\(f(x) = e^{-x^2/2}\) бол \(\hat f(\xi) = \sqrt{2\pi}\,e^{-\xi^2/2}\) — Гауссын функц Фурьегийн хувиргалтаар (тогтмол үржигдэхүүнтэйгээр) өөрчлөгдөхгүй.
🔗
Бодолт.
\(F = \hat f\) гэе. \(xe^{-x^2/2}\) абсолют интегралчлагдах тул Өгүүлбэр 11.28-ийн 5-аар
\begin{equation*} F'(\xi) = -i\int_{-\infty}^{+\infty}xe^{-x^2/2}e^{-i\xi x}dx = i\Bigl[e^{-x^2/2}e^{-i\xi x}\Bigr]_{-\infty}^{+\infty} + i\cdot i\xi\int_{-\infty}^{+\infty}e^{-x^2/2}e^{-i\xi x}dx = -\xi F(\xi) \end{equation*}
(хэсэгчлэн интегралчилсан, \((e^{-x^2/2})' = -xe^{-x^2/2}\)). Иймд \(\bigl(F(\xi)e^{\xi^2/2}\bigr)' = 0\text{,}\) \(F(\xi) = F(0)e^{-\xi^2/2}\text{,}\) \(F(0) = \int e^{-x^2/2}dx = \sqrt{2\pi}\) (Пуассоны интеграл).
