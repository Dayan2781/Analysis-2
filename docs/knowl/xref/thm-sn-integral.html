\(f\) нь \(2\pi\) үетэй, интегралчлагдах бол
\begin{equation*} S_n(x) = \frac1\pi\int_{-\pi}^{\pi}f(x+t)D_n(t)\,dt = \frac1\pi\int_0^\pi\bigl[f(x+t) + f(x-t)\bigr]D_n(t)\,dt. \end{equation*}

Коэффициентуудыг орлуулбал
\begin{equation*} S_n(x) = \frac1\pi\int_{-\pi}^{\pi}f(s)\Bigl[\frac12 + \sum_{k=1}^n(\cos ks\cos kx + \sin ks\sin kx)\Bigr]ds = \frac1\pi\int_{-\pi}^{\pi}f(s)D_n(s - x)\,ds. \end{equation*}
\(s = x + t\) орлуулаад үетэй чанараар интегралын хязгаарыг \([-\pi,\pi]\) болгоно. \(D_n\) тэгш тул \([-\pi,0]\) дээрх хэсгийг \(t\to-t\) гэж \([0,\pi]\)-д шилжүүлнэ.
