Жишээ 9.4 Тасралтгүй чанар алдагдана.

\(f_n(x) = x^n\text{,}\) \(E = [0,1]\text{:}\) \(f(x) = 0\) (\(0\le x<1\)), \(f(1) = 1\text{.}\) \(f_n\) бүр тасралтгүй боловч \(f\) нь \(x=1\) дээр тасралттай:
\begin{equation*} \lim_{x\to1^-}\lim_{n\to\infty}x^n = 0 \ne 1 = \lim_{n\to\infty}\lim_{x\to1^-}x^n. \end{equation*}
