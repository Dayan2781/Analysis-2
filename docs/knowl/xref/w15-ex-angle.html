Жишээ 15.34 Нэг холбоост нөхцөл зайлшгүй.

\(G = \R^2\setminus\{(0,0)\}\) дээр
\begin{equation*} \omega = \frac{-y\,dx + x\,dy}{x^2+y^2}, \qquad P = \frac{-y}{x^2+y^2}, \quad Q = \frac{x}{x^2+y^2}. \end{equation*}
Шууд бодоход
\begin{equation*} \frac{\partial P}{\partial y} = \frac{-(x^2+y^2) + 2y^2}{(x^2+y^2)^2} = \frac{y^2-x^2}{(x^2+y^2)^2} = \frac{(x^2+y^2) - 2x^2}{(x^2+y^2)^2} = \frac{\partial Q}{\partial x}, \end{equation*}
тэгэхээр \(\omega\) битүү. Гэтэл \(x = \cos t\text{,}\) \(y = \sin t\) нэгж тойрог дээр
\begin{equation*} \oint_{x^2+y^2 = 1}\omega = \int_0^{2\pi}\bigl(\sin^2t + \cos^2t\bigr)\,dt = 2\pi\ne0, \end{equation*}
тул Теорем 15.29-аар \(\omega\) нь \(G\) дээр бүтэн дифференциал биш. Шалтгаан нь \(G\) "нүхтэй": Грийний томьёог \((0,0)\) агуулсан дугуйд хэрэглэж болохгүй (\(P\text{,}\) \(Q\) тэнд тодорхойлогдоогүй). Харин нэг холбоост \(G_0 = \R^2\setminus\{(x,0): x\le0\}\) дээр \(\omega = d\theta\text{,}\) энд \(\theta\in(-\pi,\pi)\) нь туйлын өнцөг. Ийм учраас \(\omega\)-г өнцгийн хэлбэр гэдэг.
