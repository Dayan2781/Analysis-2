Бодлого 8.36.

\([1,\infty)\) дээр тасралтгүй, сөрөг биш, зааглагдаагүй боловч \(\int_1^\infty f\,dx\) нийлдэг функцийн жишээ байгуул.
🔗
Бодолт 1.
\(n \ge 2\) бүрд \(n\) цэг дээр өндөр нь \(n\text{,}\) суурийн өргөн нь \(\frac{2}{n^3}\) гурвалжин "шовх" байрлуулж, бусад газар \(f = 0\) гэе. Шовх бүрийн талбай \(\frac{1}{n^2}\text{,}\) шовхнууд давхцахгүй, иймд \(\int_1^\infty f = \sum_{n\ge2}\frac{1}{n^2} < \infty\text{.}\) Гэтэл \(f(n) = n\to\infty\text{.}\)
🔗
🔗
Бодолт 2. Төстэй бодлого (AI)
\([0,\infty)\) дээр тасралтгүй, сөрөг биш, зааглагдаагүй боловч \(\int_0^\infty f\,dx\) нийлдэг функцийн жишээ байгуул (\(f(n)=n^2\) байхаар).
🔗
Заавар: Бүхэл цэг дээр нарийн гурвалжин оргил.
🔗
Хариу: \(n\ge1\) бүрд \(n\) цэг дээр өндөр \(n^2\text{,}\) суурь \(\frac2{n^4}\) гурвалжин, бусад газар \(0\text{;}\) талбай \(\frac1{n^2}\text{,}\) нийлбэр нь нийлнэ.
