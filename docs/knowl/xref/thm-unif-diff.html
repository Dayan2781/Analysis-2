Теорем 9.31.

\([a,b]\) дээр \(f_n\) дифференциалчлагдах, (1) ямар нэг \(x_0\in[a,b]\) цэгт \(\{f_n(x_0)\}\) нийлдэг; (2) \(f_n'\rightrightarrows g\) (\([a,b]\) дээр) бол \(f_n\rightrightarrows f\) ба \(f' = g\text{:}\)
\begin{equation*} \Bigl(\lim_{n\to\infty}f_n\Bigr)' = \lim_{n\to\infty}f_n'. \end{equation*}

🔗

Баталгаа.
\(f_n(x) = f_n(x_0) + \int_{x_0}^x f_n'(t)\,dt\text{.}\) Теорем 9.27-ээр \(\int_{x_0}^xf_n'\rightrightarrows\int_{x_0}^xg\text{,}\) \(g\) тасралтгүй (Теорем 9.24), \(f_n(x_0)\to c\text{.}\) Иймд \(f_n\rightrightarrows f := c + \int_{x_0}^xg\text{,}\) үндсэн теоремоор \(f' = g\text{.}\)
