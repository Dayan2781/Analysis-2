Жишээ 16.3.

  1. Функцийн график \(z = f(x,y)\text{,}\) \((x,y)\in\overline D\text{,}\) \(f\in C^1\text{:}\) \(r = (x, y, f(x,y))\text{,}\) \(r_x = (1,0,f_x)\text{,}\) \(r_y = (0,1,f_y)\text{,}\)
    \begin{equation*} N = (-f_x,\ -f_y,\ 1), \qquad |N| = \sqrt{1+f_x^2+f_y^2}. \end{equation*}
    \(N\)-ийн \(z\) байгуулагч эерэг тул энэ нормаль "дээшээ" харна.
    🔗
  2. Бөмбөрцөг \(x^2+y^2+z^2 = R^2\text{:}\) \(r(\theta,\varphi) = R(\sin\theta\cos\varphi,\ \sin\theta\sin\varphi,\ \cos\theta)\text{,}\) \(\theta\in[0,\pi]\text{,}\) \(\varphi\in[0,2\pi]\text{.}\) Шууд бодоход
    \begin{equation*} r_\theta\times r_\varphi = R^2\sin\theta\,(\sin\theta\cos\varphi,\ \sin\theta\sin\varphi,\ \cos\theta) = R\sin\theta\cdot r, \qquad |N| = R^2\sin\theta. \end{equation*}
    Нормаль гадагшаа харна. \(\theta = 0,\pi\) (туйлууд) дээр \(N = 0\) — энэ нь параметрчлэлийн согог, гадаргуу өөрөө тэнд гөлгөр (өөр параметрчлэл авч болно).
    🔗
  3. Цилиндр \(x^2+y^2 = R^2\text{,}\) \(0\le z\le H\text{:}\) \(r(\varphi,z) = (R\cos\varphi, R\sin\varphi, z)\text{,}\) \(N = (R\cos\varphi, R\sin\varphi, 0)\text{,}\) \(|N| = R\text{.}\)
    🔗
  4. Тор: \(r(u,v) = \bigl((b + a\cos v)\cos u,\ (b+a\cos v)\sin u,\ a\sin v\bigr)\text{,}\) \(0<a<b\text{,}\) \(u,v\in[0,2\pi]\text{;}\) \(|N| = a(b + a\cos v)\text{.}\)
    🔗
  5. Далд хэлбэрээр өгөгдсөн гадаргуу \(\Phi(x,y,z) = 0\text{,}\) \(\nabla\Phi\ne0\text{:}\) далд функцийн теоремоор цэг бүрийн орчинд аль нэг хувьсагчаар бодогдож график болно; нормаль нь \(\nabla\Phi\text{.}\)
    🔗
