Бодлого 8.35.

\(I = \displaystyle\int_0^{\pi/2}\ln\sin x\,dx = -\frac\pi2\ln 2\) гэж батал. (Заавар: \(x = \frac\pi2 - t\) орлуулгаар \(I = \int_0^{\pi/2}\ln\cos x\,dx\text{;}\) \(2I = \int_0^{\pi/2}\ln\frac{\sin 2x}{2}\,dx\text{.}\))
🔗
Бодолт 1.
\(2I = \int_0^{\pi/2}\ln\sin 2x\,dx - \frac\pi2\ln2\text{.}\) \(t = 2x\text{:}\) \(\int_0^{\pi/2}\ln\sin2x\,dx = \frac12\int_0^\pi\ln\sin t\,dt = \frac12\cdot2I = I\) (\(\sin\)-ийн \(\frac\pi2\)-ийн тэгш хэмээр). Иймд \(2I = I - \frac\pi2\ln 2\text{,}\) \(I = -\frac\pi2\ln2\text{.}\)
🔗
🔗
Бодолт 2. Төстэй бодлого (AI)
\(\displaystyle\int_0^{\pi/2}\ln\tan x\,dx\) нийлж, \(0\)-тэй тэнцүүг батал. (Заавар: \(x=\frac\pi2-t\text{.}\))
🔗
Заавар: Нийлэлт: \(x\to0\)-д \(\ln x\text{,}\) \(\frac\pi2\)-д \(-\ln(\frac\pi2-x)\text{.}\)
🔗
Хариу: \(I=\int_0^{\pi/2}\ln\cot t\,dt=-I\) тул \(I=0\text{.}\)
