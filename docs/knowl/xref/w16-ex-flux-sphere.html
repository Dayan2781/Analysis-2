Жишээ 16.18.

  1. \(F = (x,y,z) = r\text{,}\) \(S_R\) бөмбөрцгийн гадна тал: \(n = r/R\text{,}\) \(F\cdot n = R\text{,}\) урсгал \(R\cdot4\pi R^2 = 4\pi R^3\text{.}\)
    🔗
  2. \(\iint_\Sigma z\,dx\,dy\text{,}\) \(\Sigma\) — дээд хагас бөмбөрцгийн дээд (гадна) тал: \(\iint_{x^2+y^2\le R^2}\sqrt{R^2-x^2-y^2}\,dx\,dy = 2\pi\int_0^R\sqrt{R^2-r^2}\,r\,dr = \frac{2\pi R^3}{3}\text{.}\)
    🔗
  3. \(F = \dfrac{r}{|r|^3}\) (цэгэн цэнэгийн талбар), \(S_R\)-ийн гадна тал: \(F\cdot n = \frac{r}{R^3}\cdot\frac{r}{R} = \frac{R^2}{R^4} = \frac{1}{R^2}\text{,}\) урсгал \(\frac{1}{R^2}\cdot4\pi R^2 = 4\pi\) — радиусаас хамаарахгүй!
    🔗
