Теорем 12.19 Интегралчлах.

\(\int_a^\omega f(x,y)\,dx\) нь \([c,d]\) дээр жигд нийлбэл
\begin{equation*} \int_c^d dy\int_a^\omega f(x,y)\,dx = \int_a^\omega dx\int_c^d f(x,y)\,dy, \end{equation*}
баруун талын өргөтгөсөн интеграл нийлнэ.

🔗

Баталгаа.
\(b\in(a,\omega)\)-д Теорем 12.5-ээр \(\int_a^b dx\int_c^d f\,dy = \int_c^d dy\int_a^b f\,dx\text{.}\) Иймд
\begin{equation*} \Bigl|\int_c^dF(y)\,dy - \int_a^bdx\int_c^df\,dy\Bigr| = \Bigl|\int_c^ddy\int_b^\omega f\,dx\Bigr| \le (d-c)\sup_{y\in[c,d]}\Bigl|\int_b^\omega f(x,y)\,dx\Bigr|\xrightarrow[b\to\omega]{}0. \end{equation*}
(\(F\) нь Теорем 12.18-аар тасралтгүй тул интегралчлагдана.)
