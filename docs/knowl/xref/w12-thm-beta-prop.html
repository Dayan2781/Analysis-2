2. Хэсэгчлэн интегралчилбал
\begin{equation*} B(x+1,y) = \Bigl[-\frac{t^x(1-t)^y}{y}\Bigr]_0^1 + \frac xy\int_0^1t^{x-1}(1-t)^y\,dt = \frac xyB(x,y+1). \end{equation*}
\((1-t)^y = (1-t)^{y-1} - t(1-t)^{y-1}\) тул \(B(x,y+1) = B(x,y) - B(x+1,y)\text{.}\) Орлуулбал \(B(x+1,y)\bigl(1 + \frac xy\bigr) = \frac xyB(x,y)\text{.}\) Мөн \(B(x,1) = \int_0^1t^{x-1}dt = \frac1x\text{.}\)
