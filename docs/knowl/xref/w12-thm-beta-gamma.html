Теорем 12.40 Эйлер.

\begin{equation*} B(x,y) = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}, \qquad x,y>0. \end{equation*}
🔗
🔗

Баталгаа.
1-р алхам: \(x>1\text{,}\) \(y>1\text{.}\) \(\Gamma\)-ийн интегралд \(t = (1+u)s\) (\(u\ge0\) тогтмол) орлуулбал
\begin{equation*} \frac{\Gamma(x+y)}{(1+u)^{x+y}} = \int_0^\infty s^{x+y-1}e^{-(1+u)s}\,ds. \end{equation*}
Хоёр талыг \(u^{x-1}\)-ээр үржүүлж \(u\)-ээр интегралчилбал Теорем 12.19.4-өөр
\begin{equation*} \Gamma(x+y)B(x,y) = \int_0^\infty du\int_0^\infty f(u,s)\,ds, \qquad f(u,s) = u^{x-1}s^{x+y-1}e^{-(1+u)s}\ge0. \end{equation*}
\(x,y>1\) үед \(f\) нь \([0,\infty)^2\) дээр тасралтгүй; \(\int_0^\infty f\,ds = \Gamma(x+y)\frac{u^{x-1}}{(1+u)^{x+y}}\) нь \(u\)-ээр тасралтгүй; \(s>0\) үед \(\int_0^\infty f\,du = s^{x+y-1}e^{-s}\cdot\frac{\Gamma(x)}{s^x} = \Gamma(x)s^{y-1}e^{-s}\text{,}\) энэ нь \(s = 0\)-д ч (\(y>1\)) тасралтгүй. Теорем 12.11-ээр
\begin{equation*} \Gamma(x+y)B(x,y) = \int_0^\infty\Gamma(x)s^{y-1}e^{-s}\,ds = \Gamma(x)\Gamma(y). \end{equation*}
🔗
2-р алхам: дурын \(x,y>0\text{.}\) Теорем 12.19.2 ба тэгш хэмээр \(B(x,y) = \frac{x+y}{x}B(x+1,y) = \frac{(x+y)(x+y+1)}{xy}B(x+1,y+1)\text{.}\) 1-р алхам ба \(\Gamma(z+1) = z\Gamma(z)\)-ээр
\begin{equation*} B(x,y) = \frac{(x+y)(x+y+1)}{xy}\cdot\frac{x\Gamma(x)\cdot y\Gamma(y)}{(x+y+1)(x+y)\Gamma(x+y)} = \frac{\Gamma(x)\Gamma(y)}{\Gamma(x+y)}. \end{equation*}
