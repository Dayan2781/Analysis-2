Теорем 12.6 Хувьсах хязгаартай интеграл.

\(f\text{,}\) \(f_y\) нь \([A,B]\times[c,d]\) дээр тасралтгүй, \(\alpha,\beta:[c,d]\to[A,B]\) дифференциалчлагдах бол
\begin{equation*} F(y) = \int_{\alpha(y)}^{\beta(y)}f(x,y)\,dx \ \Longrightarrow\ F'(y) = \int_{\alpha(y)}^{\beta(y)}\frac{\partial f}{\partial y}(x,y)\,dx + f\bigl(\beta(y),y\bigr)\beta'(y) - f\bigl(\alpha(y),y\bigr)\alpha'(y). \end{equation*}

Баталгаа.
\(F(y+h) - F(y)\)-ийг гурван хэсэгт задлая:
\begin{equation*} \int_{\alpha(y)}^{\beta(y)}\bigl[f(x,y+h) - f(x,y)\bigr]dx + \int_{\beta(y)}^{\beta(y+h)}f(x,y+h)\,dx - \int_{\alpha(y)}^{\alpha(y+h)}f(x,y+h)\,dx. \end{equation*}
Эхнийхийг \(h\)-д хуваагаад \(h\to0\) гэвэл Теорем 12.4-ийн баталгаагаар \(\int_{\alpha(y)}^{\beta(y)}f_y\,dx\) руу тэмүүлнэ. Хоёр дахийг дундаж утгын теоремоор \(f(\xi_h, y+h)\bigl(\beta(y+h) - \beta(y)\bigr)\) гэж бичнэ, энд \(\xi_h\) нь \(\beta(y)\text{,}\) \(\beta(y+h)\)-ийн хооронд. \(h\to0\) үед \(\xi_h\to\beta(y)\) тул \(h\)-д хуваасан хэмжигдэхүүн \(f(\beta(y),y)\beta'(y)\) руу тэмүүлнэ. Гурав дахь нь адил.
