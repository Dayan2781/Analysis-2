Лемм 14.6 Гол үнэлгээ.

\(\varphi\colon U\to V\) диффеоморфизм, \(K\subset U\) компакт байг. Дурын \(\varepsilon>0\)-д \(\delta>0\) олдож, \(K\)-д агуулагдах, тал нь \(h<\delta\text{,}\) төв нь \(a\) байх дурын куб \(Q\)-ийн хувьд
\begin{equation*} |\varphi(Q)|\le(1 + \varepsilon)^n\,|J_\varphi(a)|\,|Q|. \end{equation*}
🔗
🔗

Баталгаа.
\(|x|_\infty = \max|x_i|\) норм ба түүнд харгалзах операторын норм \(\|\cdot\|\)-ийг ашиглая; \(Q = \{x: |x - a|_\infty\le h/2\}\text{.}\) \(C = \max_K\|\varphi'(x)^{-1}\|\) (тасралтгүй функцийн максимум). \(\varphi'\) нь \(K\) дээр жигд тасралтгүй тул \(|x - a|_\infty<\delta\) үед \(\|\varphi'(x) - \varphi'(a)\|<\varepsilon/C\) байх \(\delta\) олдоно. \(A = \varphi'(a)\) ба \(\psi(x) = A^{-1}(\varphi(x) - \varphi(a)) - (x - a)\) гэвэл \(\psi(a) = 0\text{,}\)
\begin{equation*} \|\psi'(x)\| = \|A^{-1}(\varphi'(x) - A)\|\le C\cdot\frac\varepsilon C = \varepsilon \quad(x\in Q). \end{equation*}
Дундаж утгын тэнцэтгэл бишээр \(|\psi(x)|_\infty\le\varepsilon|x - a|_\infty\le\varepsilon\frac h2\text{.}\) Иймд \(A^{-1}(\varphi(x) - \varphi(a)) = (x - a) + \psi(x)\) нь тал нь \((1 + \varepsilon)h\) куб \(Q'\)-д орших бөгөөд \(\varphi(Q)\subset\varphi(a) + A(Q')\text{.}\) Теорем 14.1-аар \(|\varphi(Q)|\le|\det A|(1 + \varepsilon)^nh^n\text{.}\)
