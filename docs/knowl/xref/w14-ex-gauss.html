Жишээ 14.21 Гауссын интеграл.

\(f = e^{-(x^2 + y^2)}>0\text{.}\) Дугуйн шавхалтаар
\begin{equation*} \iint_{x^2 + y^2\le R^2}e^{-(x^2 + y^2)}dx\,dy = \int_0^{2\pi}d\theta\int_0^Re^{-r^2}r\,dr = \pi\bigl(1 - e^{-R^2}\bigr)\to\pi. \end{equation*}
Квадратын шавхалтаар (Фубини) \(\iint_{[-R,R]^2}e^{-x^2}e^{-y^2}dx\,dy = \Bigl(\int_{-R}^Re^{-x^2}dx\Bigr)^2\text{.}\) Теорем 14.4-оор хоёр хязгаар тэнцүү тул
\begin{equation*} \int_{-\infty}^{+\infty}e^{-x^2}dx = \sqrt\pi, \qquad \Gamma\bigl(\tfrac12\bigr) = \int_0^\infty t^{-1/2}e^{-t}dt\overset{t = u^2}{=}2\int_0^\infty e^{-u^2}du = \sqrt\pi. \end{equation*}
Адилаар \(\R^n\)-ийн \([-R,R]^n\) шавхалтаар \(\displaystyle\int_{\R^n}e^{-|x|^2}dx = \pi^{n/2}\text{.}\)
