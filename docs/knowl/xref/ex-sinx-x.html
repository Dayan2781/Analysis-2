Жишээ 8.25 Дирихлегийн интеграл.

\(\displaystyle\int_1^{+\infty}\frac{\sin x}{x}\,dx\) нөхцөлт нийлнэ.
🔗
Нийлэлт: \(f = \sin x\text{,}\) \(\bigl|\int_1^x\sin t\,dt\bigr| = |\cos 1 - \cos x| \le 2\text{;}\) \(g = \frac1x\downarrow0\text{.}\) Дирихлегийн шинжүүрээр нийлнэ.
🔗
Абсолют биш: \(|\sin x| \ge \sin^2 x = \frac{1 - \cos 2x}{2}\) тул
\begin{equation*} \frac{|\sin x|}{x} \ge \frac{1}{2x} - \frac{\cos 2x}{2x}. \end{equation*}
Баруун талын эхний гишүүний интеграл сарнина, хоёр дахийнх нь Дирихлегээр нийлнэ. Иймд \(\int_1^\infty\frac{|\sin x|}{x}dx = +\infty\text{.}\)
🔗
\(0\) цэг дээр \(\frac{\sin x}{x}\to1\) тул онцгой биш; иймд \(\int_0^\infty\frac{\sin x}{x}dx\) мөн нөхцөлт нийлнэ. Түүний утга \(\frac{\pi}{2}\) (Фурьегийн цувааны бүлэгт батална).
