Теорем 14.27.

\begin{equation*} \omega_n = \frac{\pi^{n/2}}{\Gamma\bigl(\frac n2 + 1\bigr)}. \end{equation*}

🔗

Баталгаа.
Жишээ 14.21 ба Өгүүлбэр 14.26-аар (\(e^{-|x|^2}\ge0\) тул бөмбөлгүүдийн шавхалт ашиглаж болно)
\begin{equation*} \pi^{n/2} = \int_{\R^n}e^{-|x|^2}dx = n\omega_n\int_0^\infty r^{n-1}e^{-r^2}dr\overset{r^2 = t}{=}n\omega_n\cdot\frac12\int_0^\infty t^{\frac n2 - 1}e^{-t}dt = \frac n2\omega_n\Gamma\bigl(\tfrac n2\bigr) = \omega_n\Gamma\bigl(\tfrac n2 + 1\bigr). \end{equation*}
