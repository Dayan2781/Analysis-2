Теорем 8.27.

\(f \ge 0\) нь \([1,\infty)\) дээр монотон буурах бол \(\int_1^\infty f\) ба \(\sum f(n)\) зэрэг нийлнэ эсвэл зэрэг сарнина. Цаашилбал \(d_N = \sum_{n=1}^N f(n) - \int_1^N f(x)\,dx\) дараалал буурах бөгөөд \([0, f(1)]\)-д төгсгөлөг хязгаартай.
🔗
🔗

Баталгаа.
\([n, n+1]\) дээр \(f(n+1) \le f(x) \le f(n)\) тул \(f(n+1) \le \int_n^{n+1}f \le f(n)\text{.}\) Нэгдүгээр хэсэг нь энэ тэнцэтгэл бишийг нийлбэрлэснээс гарна (Тоон цувааны бүлгийн интеграл шинжүүр). \(d_N - d_{N+1} = \int_N^{N+1}f - f(N+1) \ge 0\) ба \(d_N \ge f(N) \ge 0\text{,}\) \(d_N \le d_1 = f(1)\text{.}\) Монотон зааглагдсан дараалал нийлнэ.
