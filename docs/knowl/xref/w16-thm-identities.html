Теорем 16.31.

\(U, V\) скаляр, \(F, G\) вектор талбарууд хангалттай гөлгөр бол:
  1. \(\operatorname{rot}\operatorname{grad}U = 0\) (\(U\in C^2\));
    🔗
  2. \(\operatorname{div}\operatorname{rot}F = 0\) (\(F\in C^2\));
    🔗
  3. \(\operatorname{grad}(UV) = U\nabla V + V\nabla U\text{,}\) \(\operatorname{div}(UF) = U\operatorname{div}F + \nabla U\cdot F\text{;}\)
    🔗
  4. \(\operatorname{rot}(UF) = U\operatorname{rot}F + \nabla U\times F\text{;}\)
    🔗
  5. \(\operatorname{div}(F\times G) = G\cdot\operatorname{rot}F - F\cdot\operatorname{rot}G\text{;}\)
    🔗
  6. \(\operatorname{rot}\operatorname{rot}F = \operatorname{grad}\operatorname{div}F - \Delta F\) (\(\Delta F\)-г байгуулагч бүрээр).
    🔗
🔗
🔗

Баталгаа.
(1) \(\operatorname{rot}\nabla U = (U_{zy} - U_{yz},\ U_{xz} - U_{zx},\ U_{yx} - U_{xy}) = 0\) — Шварцын теоремоор. (2) \(\operatorname{div}\operatorname{rot}F = (R_y - Q_z)_x + (P_z - R_x)_y + (Q_x - P_y)_z = (R_{yx} - R_{xy}) + (P_{zy} - P_{yz}) + (Q_{xz} - Q_{zx}) = 0\text{.}\) (3) \(\partial_x(UP) = U_xP + UP_x\) гэх мэтийг нэмнэ. (5) \(F\times G = (F_2G_3 - F_3G_2,\ F_3G_1 - F_1G_3,\ F_1G_2 - F_2G_1)\)-ийн дивергенцийг үржвэрийн дүрмээр задлахад \(G\)-ийн байгуулагчдын коэффициент нь \(\operatorname{rot}F\)-ийн, \(F\)-ийнх нь \(-\operatorname{rot}G\)-ийн байгуулагчид болно. (4), (6) нь бодлого болно.
