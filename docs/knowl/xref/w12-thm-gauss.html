Теорем 12.26 Эйлер–Пуассоны интеграл.

\begin{equation*} \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt\pi}{2}. \end{equation*}
🔗
🔗

Баталгаа.
\(I = \int_0^\infty e^{-x^2}dx\) (нийлнэ: \(x\ge1\) үед \(e^{-x^2}\le e^{-x}\)). \(y>0\) үед \(x = yt\) орлуулгаар \(I = \int_0^\infty ye^{-y^2t^2}dt\text{.}\) \(c>0\)-г тогтоогоод
\begin{equation*} I\int_c^\infty e^{-y^2}dy = \int_c^\infty dy\int_0^\infty ye^{-(1+t^2)y^2}dt. \end{equation*}
\(f(t,y) = ye^{-(1+t^2)y^2}\ge0\) нь \([0,\infty)\times[c,\infty)\) дээр тасралтгүй; \(\int_0^\infty f\,dt = Ie^{-y^2}\) ба \(\int_c^\infty f\,dy = \frac{e^{-(1+t^2)c^2}}{2(1+t^2)}\) хоёулаа тасралтгүй. Теорем 12.22-ээр
\begin{equation*} I\int_c^\infty e^{-y^2}dy = \int_0^\infty\frac{e^{-(1+t^2)c^2}}{2(1+t^2)}\,dt. \end{equation*}
Баруун талын интеграл доорх функц \(\le\frac{1}{2(1+t^2)}\) тул \(c\in[0,1]\) дээр жигд нийлж, \(c\)-ээр тасралтгүй (Теорем 12.18). \(c\to0^+\) гэвэл \(I^2 = \int_0^\infty\frac{dt}{2(1+t^2)} = \frac\pi4\text{.}\)
