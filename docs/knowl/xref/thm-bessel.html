Теорем 11.10 Хамгийн сайн ойролцоолол ба Бессель.

\(f\) интегралчлагдах, \(T_n(x) = \frac{\alpha_0}{2} + \sum_{k=1}^n(\alpha_k\cos kx + \beta_k\sin kx)\) дурын \(n\)-р эрэмбийн тригонометр олон гишүүнт бол
\begin{equation*} \int_{-\pi}^{\pi}(f - T_n)^2\,dx \ge \int_{-\pi}^{\pi}(f - S_n)^2\,dx = \int_{-\pi}^{\pi}f^2\,dx - \pi\Bigl[\frac{a_0^2}{2} + \sum_{k=1}^n(a_k^2+b_k^2)\Bigr]. \end{equation*}
Ялангуяа Бесселийн тэнцэтгэл биш биелнэ:
\begin{equation*} \frac{a_0^2}{2} + \sum_{k=1}^\infty(a_k^2 + b_k^2) \le \frac1\pi\int_{-\pi}^{\pi}f^2(x)\,dx. \end{equation*}

Баталгаа.
Лемм 11.2-аар \(\int T_n^2 = \pi\bigl[\frac{\alpha_0^2}{2} + \sum(\alpha_k^2 + \beta_k^2)\bigr]\) ба коэффициентын тодорхойлолтоор \(\int fT_n = \pi\bigl[\frac{\alpha_0a_0}{2} + \sum(\alpha_ka_k + \beta_kb_k)\bigr]\text{.}\) Иймд
\begin{equation*} \int(f - T_n)^2 = \int f^2 - 2\int fT_n + \int T_n^2 = \int f^2 - \pi\Bigl[\frac{a_0^2}{2} + \sum(a_k^2+b_k^2)\Bigr] + \pi\Bigl[\frac{(\alpha_0 - a_0)^2}{2} + \sum\bigl((\alpha_k - a_k)^2 + (\beta_k - b_k)^2\bigr)\Bigr]. \end{equation*}
Сүүлийн хаалт \(\ge0\) бөгөөд \(T_n = S_n\) үед \(0\text{.}\) Зүүн тал \(\ge0\) тул \(\frac{a_0^2}{2} + \sum_{k\le n}(a_k^2+b_k^2)\le\frac1\pi\int f^2\text{;}\) \(n\to\infty\text{.}\)
