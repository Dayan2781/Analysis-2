Теорем 12.23 Дирихлегийн интеграл.

\begin{equation*} \int_0^\infty\frac{\sin\alpha x}{x}\,dx = \frac\pi2\operatorname{sign}\alpha. \end{equation*}
🔗
🔗

Баталгаа.
\(I(t) = \int_0^\infty e^{-tx}\frac{\sin x}{x}\,dx\text{,}\) \(t\ge0\) гэе (\(x = 0\) дээр интеграл доорх функцийг \(1\) гэж тодорхойлбол тасралтгүй).
  1. Жишээ 12.5-аар \([0,\infty)\) дээр жигд нийлэх тул \(I\) нь \([0,\infty)\) дээр тасралтгүй (Теорем 12.8).
    🔗
  2. \(t\ge t_0>0\) үед \(\bigl|\frac{\partial}{\partial t}\bigl(e^{-tx}\frac{\sin x}{x}\bigr)\bigr| = |e^{-tx}\sin x|\le e^{-t_0x}\) — M-шинжүүрээр жигд. Теорем 12.10-ээр \((0,\infty)\) дээр
    \begin{equation*} I'(t) = -\int_0^\infty e^{-tx}\sin x\,dx = -\frac{1}{1+t^2}. \end{equation*}
    🔗
  3. Иймд \(I(t) = C - \arctan t\text{.}\) Гэтэл \(\bigl|\frac{\sin x}{x}\bigr|\le1\) тул \(|I(t)|\le\int_0^\infty e^{-tx}dx = \frac1t\to0\text{,}\) эндээс \(C = \frac\pi2\text{.}\)
    🔗
1-ээр \(I(0) = \lim_{t\to0^+}I(t) = \frac\pi2\text{.}\) \(\alpha>0\) үед \(\alpha x = u\) орлуулгаар \(\int_0^\infty\frac{\sin\alpha x}{x}dx = I(0)\text{;}\) \(\alpha<0\) үед сондгой чанараар.
