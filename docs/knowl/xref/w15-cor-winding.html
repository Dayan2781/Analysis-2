Мөрдөлгөө 15.35.

\(\gamma\) нь \((0,0)\)-ийг дотроо агуулах, эерэг чиглэлтэй хэсэгчлэн гөлгөр Жорданы муруй бол \(\oint_\gamma\omega = 2\pi\text{;}\) \((0,0)\)-ийг дотроо агуулахгүй бол \(0\text{.}\)
🔗
🔗

Баталгаа.
Агуулахгүй бол \(\gamma\)-ийн дотоод муж дээр Грийнийг хэрэглэнэ. Агуулж байвал хангалттай бага \(\varepsilon\)-д \(C_\varepsilon\text{:}\) \(x^2+y^2 = \varepsilon^2\) тойрог \(\gamma\)-ийн дотор оршино. \(\gamma\) ба \(C_\varepsilon\)-ийн хоорондох \(D_\varepsilon\) мужид Грийнийг хэрэглэвэл (\(\partial D_\varepsilon = \gamma + C_\varepsilon^-\)) \(\oint_\gamma\omega - \oint_{C_\varepsilon}\omega = \iint_{D_\varepsilon}0 = 0\text{.}\) Жишээ 15.9-ийн тооцоо ямар ч радиуст адил тул \(\oint_{C_\varepsilon}\omega = 2\pi\text{.}\)
