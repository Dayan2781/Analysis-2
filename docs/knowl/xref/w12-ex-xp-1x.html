Жишээ 12.47.

  1. \(0<p<1\) үед \(\displaystyle\int_0^\infty\frac{x^{p-1}}{1+x}\,dx = \frac{\pi}{\sin p\pi}\) (Теорем 12.21).
    🔗
  2. \(n>1\) үед \(\displaystyle\int_0^\infty\frac{dx}{1+x^n}\overset{t = x^n}{=}\frac1n\int_0^\infty\frac{t^{\frac1n - 1}}{1+t}dt = \frac{\pi/n}{\sin(\pi/n)}\text{.}\) Жишээ нь \(n = 2\text{:}\) \(\frac\pi2\text{;}\) \(n = 4\text{:}\) \(\frac{\pi}{2\sqrt2}\text{.}\)
    🔗
  3. \(a>0\text{,}\) \(s>0\) үед \(\displaystyle\int_0^\infty x^{s-1}e^{-ax}\,dx = \frac{\Gamma(s)}{a^s}\text{;}\) \(\displaystyle\int_0^\infty x^{2n}e^{-x^2}dx\overset{t = x^2}{=}\frac12\Gamma\Bigl(n+\frac12\Bigr) = \frac{(2n-1)!!}{2^{n+1}}\sqrt\pi\text{.}\)
