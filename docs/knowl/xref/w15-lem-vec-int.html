Лемм 15.6.

\(F = (F_1,\dots,F_n):[a,b]\to\R^n\) тасралтгүй бол \(\displaystyle\Bigl|\int_a^bF(t)\,dt\Bigr|\le\int_a^b|F(t)|\,dt\) (вектор функцийн интегралыг координатаар нь авна).
🔗
🔗

Баталгаа.
\(u = \int_a^bF\,dt\) гэе. \(u = 0\) бол батлах зүйлгүй. Үгүй бол Кошийн–Буняковскийн тэнцэтгэл бишээр
\begin{equation*} |u|^2 = \sum_{k=1}^nu_k\int_a^bF_k\,dt = \int_a^bu\cdot F(t)\,dt\le|u|\int_a^b|F(t)|\,dt, \end{equation*}
хоёр талыг \(|u|\)-д хуваана.
