Теорем 10.13 Гишүүнчлэн дифференциалчлах ба интегралчлах.

\(S(x) = \sum_{n=0}^\infty a_nx^n\text{,}\) радиус \(R>0\) бол \((-R,R)\) дээр
  1. \(S\) дифференциалчлагдах ба \(\displaystyle S'(x) = \sum_{n=1}^\infty na_nx^{n-1}\text{;}\)
    🔗
  2. \(\displaystyle\int_0^xS(t)\,dt = \sum_{n=0}^\infty\frac{a_n}{n+1}x^{n+1}\text{;}\)
    🔗
  3. \(S\) дурын эрэмбээр дифференциалчлагдах ба \(\displaystyle a_n = \frac{S^{(n)}(0)}{n!}\text{.}\)
    🔗
🔗
🔗

Баталгаа.
1. \(|x|<r<R\) гэе. Лемм 10.12-аар уламжлалын цуваа \(R\) радиустай тул \([-r,r]\) дээр жигд нийлнэ (Теорем 10.10). \(\sum a_n\cdot0^n\) нийлнэ. Мөрдөлгөө 9.33-аар гишүүнчлэн дифференциалчилж болно.
🔗
2. \([0,x]\) (эсвэл \([x,0]\)) \(\subset[-r,r]\) дээр жигд нийлэх тул Мөрдөлгөө 9.28-аар.
🔗
3. 1-ийг давтан хэрэглэвэл \(S^{(k)}(x) = \sum_{n\ge k}n(n-1)\cdots(n-k+1)a_nx^{n-k}\text{.}\) \(x = 0\) үед зөвхөн \(n=k\) гишүүн үлдэнэ: \(S^{(k)}(0) = k!a_k\text{.}\)
